# Contributing

Thanks for your interest in improving *Harness Engineering*.

- **Typos and small fixes:** edit the file under `src/` and open a pull
  request — or use the edit (pencil) icon on any page of the [rendered
  book](https://sidhpurwala-huzaifa.github.io/harness-engg/), which brings you
  to the right file.
- **Errors or unclear passages:** open an issue naming the chapter and quoting
  the passage.
- **New material:** open an issue to discuss scope before writing.

To preview changes locally: `cargo install mdbook && mdbook serve --open`.

By contributing you agree that your contributions are licensed under the same
terms as the book: [CC BY 4.0](LICENSE) for text and figures,
[MIT](LICENSE-CODE) for code samples.
