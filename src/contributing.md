# Contributing

This book is built from a public GitHub repository:
**<https://github.com/sidhpurwala-huzaifa/harness-engg>**

Corrections, clarifications, and suggestions are welcome.

## Quick fixes

Every page has an edit icon (pencil, top right) that takes you straight to
that page's source on GitHub — fix the typo, and GitHub walks you through
opening a pull request.

## Larger changes

- **Found an error or unclear passage?** [Open an
  issue](https://github.com/sidhpurwala-huzaifa/harness-engg/issues) with the
  chapter and a quote of the passage.
- **Want to propose new material?** Open an issue first to discuss scope
  before writing — the book tries hard to stay opinionated and compact.

## Building locally

The book is an [mdBook](https://rust-lang.github.io/mdBook/) project:

```bash
git clone https://github.com/sidhpurwala-huzaifa/harness-engg
cd harness-engg
cargo install mdbook
mdbook serve --open
```
